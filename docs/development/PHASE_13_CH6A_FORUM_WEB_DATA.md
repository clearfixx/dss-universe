Status: implementation package under review, on top of the Application Shell
branch (`feature/application-shell-v1`, PR #111) with current `main` merged.

## What is in `apps/web/src/features/forum`

| File               | Role                                                                                                                                                                                                                                                                  |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `forum-data.ts`    | server-only loaders: categories with activity, topic lists (sort, filter, scope, tag), personal lists, thread (topic + posts), viewer state, poll, voters, tags, revisions                                                                                            |
| `forum-actions.ts` | server actions for members (topic, reply, edit, vote, accept, close/reopen, follow, read, view, poll, tags) and moderators (pin, curator, archive, trash, move, merge, split, move posts, hide/delete/restore, purge, staff notes, vote reversal, warning, read-only) |
| `forum-errors.ts`  | typed `ForumResult` and error mapping: `NOT_SIGNED_IN`, `READ_ONLY` (with end date), `RATE_LIMITED`, `ACCESS_DENIED`, `NOT_FOUND`, `CONFLICT`, `INVALID_INPUT`, `UNKNOWN`                                                                                             |
| `forum-format.ts`  | display rules: net score, "80+ / 10−" breakdown, member name, unread count and first unread post                                                                                                                                                                      |

GraphQL operations: `src/graphql/operations/forum.graphql` and
`forum-moderation.graphql`; types are generated by `graphql:codegen`.

## Rules carried into the client

- The API decides visibility; loaders forward the viewer session and return
  `null` for missing or hidden topics so pages can render a 404.
- Actions never throw to the browser; they return `ForumResult`, and accept a
  `revalidate` path for the page that shows the changed data.
- The rating column shows the net score, the tooltip shows "80+ / 10−" and a
  click opens the voters list (owner decision, 2026-11-20).
- Forum structure administration (Command Deck) is not part of this package.
