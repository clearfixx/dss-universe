# DSS Universe Version History

> This document records the major milestones in the evolution of DSS Universe.
>
> Unlike the CHANGELOG, this document focuses on project history rather than individual changes.

---

# Purpose

The Version History provides a high-level timeline of the project's evolution.

Its goal is to document significant milestones, completed phases, architectural progress, and major engineering achievements.

---

# Format

Each version should include:

- release date;
- version number;
- completed missions;
- major engineering changes;
- architectural milestones;
- next objectives.

# Philosophy

Version History tells the story of the project.

It should describe where the project has been, where it is today, and where it is heading next.

Unlike commit history, this document focuses on the project's long-term evolution.
