## Interpretation Rules

The mockups describe design direction and product intent. They are not database or permission specifications.

- **Canonical reference** — preferred source for the named screen or component family.
- **Supporting reference** — approved ideas/components that may be combined with the canonical reference.
- **Alternative** — useful exploration, not a pixel-perfect implementation target.
- **Historical** — contains outdated branding, terminology, architecture or scope.

All mockups must be rebranded to DSS Universe and use the canonical names in `docs/product/MODULE_MAP.md`.

## Visual Direction

The consistent approved direction is:

- dark, high-contrast space-station aesthetic;
- deep navy surfaces with purple/blue accents;
- restrained neon glows rather than permanent high-intensity effects;
- dense desktop information architecture with responsive simplification;
- astronaut/space imagery as branded illustration, not functional UI chrome;
- semantic success, warning, danger and information colors;
- light theme supported by Theme Engine even when most mockups show dark mode.
