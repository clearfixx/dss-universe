
DSS Universe Frontend Style
Frontend principles
UI should feel like a living system, not static pages.
Components should be small and understandable.
Business logic should not be hidden inside visual components.
Shared UI belongs in reusable components.
Page-level components compose features, not contain everything.
DSS Universe UI philosophy

The interface should feel like a space station:

alive;
interactive;
modular;
clear;
atmospheric.
Component rules
Components should have clear names.
Avoid huge components.
Extract repeated UI.
Keep server/client boundaries obvious.
Do not turn every component into use client without reason.
