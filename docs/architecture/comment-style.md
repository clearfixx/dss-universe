# DSS Universe Comment Style

## File header standard

Every new source file should start with a DSS Universe header.

```ts
/**
 * ===============================================================
 * 🚀 DSS Universe
 * ---------------------------------------------------------------
 * 📦 Module: ModuleName
 * 📄 File: file-name.ts
 *
 * 🎯 Purpose:
 * Short explanation of what this file does.
 *
 * 🧠 Responsibilities:
 * • responsibility one;
 * • responsibility two;
 * • responsibility three.
 *
 * ⚠️ Important:
 * Important architectural notes or warnings.
 *
 * 💡 Future:
 * ▢ planned improvement;
 * ▢ planned extension.
 *
 * 🚀 Build. Share. Grow.
 * ===============================================================
 */
Tone

Comments may include light humor, emojis, and Easter eggs.

But implementation code should stay clean.

Rule

Funny comments belong mostly in file headers, not inside business logic.
