# DSS Universe Standards

This directory contains the internal engineering standards of DSS Universe.

These standards define how we write, structure, document, review, and evolve the project.

## Rule

No important technical decision should exist only in chat.

If a decision affects architecture, code style, folder structure, authorization, database design, or development workflow, it should eventually be documented here or in ADR.

## Current Standards

- `philosophy.md` — engineering philosophy
- `architecture.md` — architectural principles
- `backend.md` — backend rules
- `frontend.md` — frontend rules
- `comments.md` — code comments rules
- `imports.md` — imports and exports rules
- `naming.md` — naming rules
- `folders.md` — folder structure rules
- `git.md` — Git workflow rules
- `testing.md` — testing principles
