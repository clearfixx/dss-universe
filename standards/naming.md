# Naming Standard

Names should be clear, explicit, and consistent.

## DTOs

```ts
CreateUserDto
UpdateProfileDto
LoginDto
Types
AuthenticatedUser
JwtPayload
Guards
JwtAuthGuard
RolesGuard
Decorators
Authenticated
AuthUser
Roles
Files

Use kebab-case:

auth-user.decorator.ts
roles.guard.ts
authenticated-user.type.ts
Rule

Do not optimize names for shortness. Optimize names for clarity.
```
