# DSS Universe Engineering Philosophy

DSS Universe is built as a long-term product.

We prefer:

- simplicity over cleverness;
- readability over shortcuts;
- explicit code over magic;
- architecture over rush;
- documented decisions over verbal agreements;
- long-term maintainability over short-term speed.

Every important technical decision should go through discussion, approval, implementation, documentation, and freeze.

## Core Rule

Every change should leave the project in a better state than before.
