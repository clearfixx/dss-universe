# Research Lab module

Research Lab owns the single DSS Universe Wiki and long-form research product.
`Knowledge Forge` is a historical product alias; the technical `WIKI` Editor
profile and Guardian capability remain compatible identifiers.

This initial package establishes the page, draft, immutable revision, review,
organization and audience schema plus closed lifecycle rules. It exposes no
public API and performs no publication yet.

Editor owns document validation and projections. IAM/Authorization owns current
group and Guardian evidence. Interactions, Media, Search, Activity and
Gamification retain their existing ownership. Root composition will bind their
narrow contracts in later packages.

🧭 A Wiki without history is just a text box with excellent confidence.
